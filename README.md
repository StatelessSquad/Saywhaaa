# Saywhaaa

A simple todo list app built with Vite, TypeScript, and Vitest, with E2E tests using Playwright.

## Features

- Add, toggle, and delete todos
- Persists todos in localStorage
- Responsive design
- Fully tested with unit and E2E tests

## Development

### Setup

```bash
npm ci
```

### Development Server

```bash
npm dev
```

### Run Tests

```bash
# Unit tests
npm test

# E2E tests (requires a running preview server)
npm run preview & npm run e2e
```

### Linting

```bash
npm run lint
```

### Formatting

```bash
npm run format
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Deployment

The app is automatically deployed to GitHub Pages on push to the `main` branch.
